# Date Course Checklist

## Venue fit

- Noise level acceptable?
- Seating comfortable?
- Menu has partner-safe options?
- Reservation feasible?
- Does the venue require a dress code or long course that may feel tiring?
- Is it near a pleasant second stop?

## Timely reasons

- New opening or renovation
- Seasonal menu
- Chef/menu award or media mention
- Neighbourhood date trend
- Exhibition/performance nearby
- Personal memory nearby

## Low-energy version

When partner is tired, choose:

- short travel distance
- familiar comfort food
- dessert takeaway
- early return
- no pressure to dress up
- handwritten note
