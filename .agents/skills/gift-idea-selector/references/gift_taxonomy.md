# Gift Taxonomy

## Low-pressure gifts

- Favourite dessert, chocolate, tea, coffee beans
- Flowers, especially if paired with one specific note
- Small luxury consumable: candle, bath item, hand cream, perfume sample set
- Book or stationery linked to their current interest
- Handwritten letter plus one practical support action

## Medium gifts

- Spa or hotel afternoon tea voucher, only if the partner likes scheduled experiences
- Jewellery with clear style preference
- Premium scarf, bag charm, wallet, perfume, skincare she already uses
- Class or workshop for an interest she already has
- Concert, musical, exhibition, or art event tickets

## Premium gifts

- Overnight staycation
- Weekend trip
- Fine-dining course
- Designer item only when exact preference/size/colour is known
- Bespoke experience linked to a shared memory

## Avoid unless explicitly requested

- Fitness/diet/anti-ageing products
- Cleaning/cooking appliances framed as a gift
- Very public surprises if the partner dislikes attention
- Pets or high-maintenance living things
- Expensive irreversible purchases without return path
