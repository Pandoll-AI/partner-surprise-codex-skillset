# 운영 매뉴얼

## 핵심 운영 방식

이 스킬셋은 세 단계로 움직입니다.

1. 트리거 감지: 어떤 이유로 지금 챙길 만한가?
2. 후보 조사: 선물, 식당, 여행, 메시지 중 무엇이 맞는가?
3. 실행 플랜: 실제로 오늘 무엇을 예약/구매/말할 것인가?

## 추천 루틴

### 매일 1분

`daily_trigger_radar` 자동화를 보고 오늘 할 수 있는 작은 행동이 있는지 확인합니다.

### 매주 10분

`weekly_surprise_scan`으로 이번 주/다음 주에 가능한 이벤트를 고릅니다.

### 매월 20분

`monthly_trend_watch`로 식당, 전시, 호텔, 선물 트렌드를 모읍니다.

## 프로필 업데이트 원칙

파트너가 좋다고 한 것, 싫다고 한 것, 부담스러워한 것을 짧게 기록합니다.

예:

```json
{
  "date": "2026-07-02",
  "action": "flowers + short letter",
  "reaction": "positive",
  "learning": "Partner liked low-pressure handwritten notes."
}
```

## 좋은 서프라이즈의 기준

- 작은데 구체적이다.
- 내가 먼저 준비했다는 느낌이 있다.
- 파트너가 추가로 일하지 않아도 된다.
- 거짓 이유가 아니라 실제 이유가 있다.
- 실패해도 부담이 크지 않다.

## 피해야 할 패턴

- “네가 뭐라고 해서 내가 했다”는 느낌
- 예약만 해놓고 준비는 파트너에게 맡기는 것
- 취향과 맞지 않는 비싼 선물
- 사람들이 보는 앞에서 하는 이벤트
- 최신 트렌드라고 말하지만 실제 근거가 없는 추천
