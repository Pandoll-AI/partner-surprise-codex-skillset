# 출력 예시

## 예시: 깊은 대화 다음 날

# 이번 서프라이즈 추천

## 1. 트리거 / 자연스러운 이유

- 이유: 어제 파트너가 “의외성, 서프라이즈, 먼저 챙겨주는 느낌”을 원한다고 분명히 이야기함.
- 왜 지금인지: 대화 직후 24–48시간 안에 작은 행동으로 보여주는 것이 가장 진심 있게 느껴질 수 있음.
- 근거 상태: 개인 맥락 기반, 트렌드 검증 불필요.

## 2. 추천 액션

- 핵심 아이디어: 짧은 손편지 + 좋아하는 디저트 + 저녁의 한 가지 부담 제거.
- 예상 감정 효과: “말로만 약속한 것이 아니라 바로 행동했다”는 느낌.
- 준비 난이도: 낮음.
- 예산: 3만–7만 원.

## 3. 말할 문장

“어제 이야기 듣고 내가 좀 많이 루틴하게만 지냈다는 생각이 들었어. 거창한 건 아니지만 오늘은 당신이 조금 편했으면 해서 준비했어.”

## 4. 플랜 B

디저트가 어렵다면 꽃이나 차, 혹은 집안일 한 가지를 먼저 끝내고 짧은 메모만 남긴다.
