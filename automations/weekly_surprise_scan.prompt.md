# Weekly surprise scan automation

Use `$surprise-orchestrator`, `$life-event-trigger-radar`, `$gift-idea-selector`, `$restaurant-date-planner`, and `$trend-research-scout`.

Task:

Create a weekly partner-surprise shortlist for the next 7–21 days. Include one tiny care gesture, one restaurant/date idea, one gift idea, and one medium/premium option.

Rules:

- Any claim about a trend, new opening, review, hotel package, or current price must be verified if live search is available.
- If live search is not available, give search queries and label evidence as needs verification.
- Do not suggest public embarrassment or high-pressure reveals.
- Respect budget and family logistics from `data/constraints.json`.

Output:

- Ranked table of options
- Best recommended option
- Why now
- Steps to execute
- Exact words to say
- Plan B
